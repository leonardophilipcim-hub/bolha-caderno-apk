📚 Bolha 1.8.20

App de flashcards pra Direito/GCM com 26 padrões de geração automática.

Tamanho: 1.2 MB

Versão: 1.8.20

Compatibilidade: Android 7.0+

Assinatura: Debug (não vai pra Play Store)

⬇️ Baixar APK

Como instalar

  1. Baixe o APK acima
  2. Desinstale versão antiga (se tiver)
  3. Habilite "Fontes desconhecidas" nas Configurações
  4. Abra o APK baixado
  5. Conceda permissões (Overlay + Notificações)

26 padrões de flashcards

  • prescreve — prazos prescricionais
  • nulidade — quando é nulo
  • conforme/segundo — citações
  • prazo para — prazos processuais
  • pena — reclusão, detenção, multa
  • sujeito — ativo/passivo
  • elemento — subjetivo/objetivo
  • dolo/culpa — crime doloso/culposo
  • artigo — "art. X trata de Y"
  • procedimento — comum/especial/sumaríssimo
  • competência — quem julga
  • cautelar — prisão preventiva
  • recurso — apelação, agravo
  • prazo em dobro — Fazenda Pública
  • excludente — legítima defesa
  • princípio — insignificância
  • consumado/tentado — iter criminis
  • autoria — coautor, partícipe
  • reincidência
  • punibilidade — extinta/suspensa
  • lei benéfica — retroatividade
  • sursis — suspensão condicional
